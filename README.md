# Idea Farm Client Hub (trial build)

Clients send requests and approve work here instead of by email. The team answers, updates status and sends approvals. Planned home: **hub.theideafarm.com** on Webflow Cloud.

**Status: step 2 of the trial plan.** Works on this computer with sample data. Nothing is sent to GHL or monday yet: those events wait in the team's **Outbox** page until step 4.

## Run it

```bash
npm install
npm run db:reset   # creates the local database and loads sample data
npm run dev        # http://localhost:4183
```

To test the real Webflow Cloud build locally (Cloudflare Workers runtime):

```bash
npx opennextjs-cloudflare build
npm run preview:worker   # http://localhost:4184
```

Test logins are generated by `npm run db:seed` and saved to `seed/dev-logins.txt` (local only, not real accounts).

## How it's built

- **Next.js 15** on Cloudflare's runtime via `@opennextjs/cloudflare`, which is what Webflow Cloud runs.
- **SQLite (D1)** database through Drizzle. Schema: `src/db/schema.ts`. Migrations: `migrations/`.
- **File storage (R2)** for photos and PDFs clients attach. Files are only served to the client company that owns them, and to the team.
- **Logins:** one shared login per client company. The person types their name on each request, and it's remembered on that device. Passwords are hashed (PBKDF2).
- **Outbox** (`src/lib/outbox.ts`): every client email (GHL) and monday update is queued here. Step 4 replaces "queue" with real delivery.

| Where | What |
|---|---|
| `src/app/(client)/` | Client screens: home, ask us, sent, requests, request, approvals |
| `src/app/team/` | Team screens: inbox, request, approvals, log a request, outbox |
| `src/app/actions.ts` | Everything that saves |
| `src/lib/sentences.ts` | The plain-language lines clients see (shared with the team's preview) |
